Bem-vindo(a) ao meu repositório de estudos! Aqui eu centralizo todos os scripts, exercícios e projetos práticos que desenvolvi durante o meu Curso de Python Básico.
O objetivo deste espaço é documentar minha evolução na linguagem e servir como fonte de consulta para outros iniciantes.
🚀 O que você vai encontrar aqui?
Os arquivos estão organizados por módulos/temas para facilitar a navegação:
Fundamentos: Variáveis, tipos de dados e operadores matemáticos.
Estruturas de Condição: Exercícios com if, elif e else.
Laços de Repetição: Exemplos práticos usando while e for.
Estruturas de Dados: Manipulação de Listas, Tuplas e Dicionários.
Funções: Criação de blocos de código reutilizáveis.
Desafios: Pequenos programas como calculadoras, jogos de adivinhação e simuladores.
