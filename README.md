# 🐍 Minha Jornada no Python Básico

Bem-vindo(a) ao meu repositório de estudos! Este espaço foi criado para centralizar todos os scripts, exercícios e projetos práticos que desenvolvi durante o meu **Curso de Python Básico**.

O objetivo aqui é documentar minha evolução na linguagem e servir como uma fonte de consulta amigável para outros iniciantes.

---

## 🚀 O que você vai encontrar aqui?

Os arquivos estão organizados por módulos temáticos para facilitar a sua navegação:

*   **📂 Fundamentos:** Variáveis, tipos de dados e operadores matemáticos.
*   **⚖️ Estruturas de Condição:** Exercícios focados em lógica com `if`, `elif` e `else`.
*   **🔄 Laços de Repetição:** Exemplos práticos utilizando as estruturas `while` e `for`.
*   **📦 Estruturas de Dados:** Manipulação e métodos de Listas, Tuplas e Dicionários.
*   **🛠️ Funções:** Criação e organização de blocos de código reutilizáveis.
*   **🏆 Desafios:** Pequenos programas completos, como calculadoras, jogos de adivinhação e simuladores.

## 💻 Como utilizar

1. Navegue pelas pastas acima para encontrar o tema desejado.
2. Cada pasta contém scripts `.py` com comentários explicativos.
3. Fique à vontade para clonar o repositório e testar os códigos localmente!

```bash
git clone https://github.com
```
